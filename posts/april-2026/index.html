RoguePlanetoid Weekly Update #93

1st April 2026

Last week it was the MVP Summit which was head at the headquarters of Microsoft in Seattle, I wasn't there in person but was able to attend virtually, it is a great chance to hear things and get insights but unfortunately that's all that I can say other than appreciating the opportunity to do this as a Microsoft MVP and hopefully one day will be able to go to the MVP Summit in person! I was lucky enough to be in Seattle for Microsoft Build 2012 and that led to so many things in my professional and personal life so would be great to be able to go back there and catch many of the things I missed out or get to see once again!

Last week I also participated in a company hackathon where I build an server-sent events based Model Context Protocol example which was really interesting to try after using a stdio or Console-based Model Context Protocol example for my talk, Take a Note of UI with .NET 10, this example will actually form the basis for a Workshop I will be creating later in the year at Tutorialr.com as well as aiming to deliver it in person as part of TechNExt this year, last year there I showed off my Workshop on Blazor Podcast AI with my session Build a Podcast AI with Blazor using GitHub Models and hope to do so again this year!

This week sees an episode of the RoguePlanetoid Podcast about Visual Basic, Visual Basic was my first foray into developing applications for the desktop and later the web and is great to look back on that part of my journey as a developer! Although I switched to C# when Windows Phone was released as it didn't support Visual Basic, and have used that ever since. It is great to think back to that experience and to share that, it was sharing my experience of learning Visual Basic that got me into writing Tutorials, and aim to share some for the first time in years this year!
